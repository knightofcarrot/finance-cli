# Personal Finance Manager (CLI)

Консольное приложение для удобного учета личных финансов, управления категориями расходов и доходов, а также просмотра аналитики за различные периоды. Проект разработан в рамках командной работы.

---

## Основные возможности

- **Учет доходов и расходов:** Быстрое добавление финансовых операций с указанием суммы, категории и опционального описания.
- **Подсчет баланса:** Автоматический расчет суммарных доходов, расходов и итогового баланса.
- **Управление категориями:** Динамическое добавление и удаление категорий операций.
- **Статистика и аналитика:** 
  - Финансовый отчет за указанный месяц (`ММ.ГГГГ`).
  - Наглядное распределение расходов по категориям за выбранный период.
- **Надежное хранение:** Автоматическое сохранение данных в формате `JSON` с корректной обработкой пустых и первичных состояний базы.

- **Язык программирования:** Python 3.10+
- **Формат хранения данных:** JSON

## Пример использования

При запуске программы вы увидите следующее главная меню:

```text
==================== PERSONAL FINANCE MANAGER ====================
1. Добавить доход
2. Добавить расход
3. Посмотреть баланс
4. Добавить категорию
5. Удалить категорию
6. Показать категории
7. Статистика за месяц
8. Статистика расходов по категориям
0. Выход
```
